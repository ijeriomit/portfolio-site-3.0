# Services Page

## Purpose

Explain the services I offer and make it clear how I can help potential clients.

The page should feel professional, concise, and conversion-focused while using less vertical space than the original design.

The approved mockup is the source of truth.

---

## Layout

The hero graphic has been removed.

The desktop page uses a two-column layout for the upper content.

### Top Section

#### Left — What I Do

Contains:

* `WHAT I DO`
* `SERVICES THAT DRIVE REAL IMPACT.`
* Supporting description
* `START A PROJECT` button
* `VIEW CASE STUDIES` button

The headline and supporting content remain consistent with the approved design.

#### Right — Who I Work With

The `WHO I WORK WITH` section is positioned beside the `WHAT I DO` section at the same vertical level.

It contains four audiences:

1. Startups
2. Businesses
3. Agencies
4. Founders

Each audience includes:

* Icon
* Audience name
* Short description

This is a vertical list on desktop.

---

## How I Can Help

The four services appear below the top two-column section.

Services:

### Full Stack Development

End-to-end web applications that are scalable, secure, and built for performance.

### UI / UX Design

Intuitive, accessible, and engaging designs that users love and businesses rely on.

### AI & Automation Solutions

AI-powered features and automation that streamline workflows and deliver intelligent experiences.

### Technical Consulting

Expert guidance to solve complex technical challenges and scale products with confidence.

Each service includes:

* Icon
* Service name
* Short description
* `LEARN MORE` action

---

## Bottom CTA

The bottom of the page contains two supporting cards.

### Have a Project in Mind?

Encourages the visitor to start a conversation.

Contains:

* Chat/contact icon
* `Have a project in mind?`
* Short supporting text
* `LET'S TALK` button

### View My Work

Provides a secondary path to the portfolio.

Contains:

* `VIEW MY WORK`
* Short supporting statement
* `VIEW CASE STUDIES` button

# Mobile Layout

The desktop two-column structure becomes a vertical mobile layout.

Order:

1. Navigation
2. What I Do
3. Who I Work With
4. How I Can Help
5. Have a Project in Mind?
6. View My Work

### Who I Work With

On mobile, the four audiences become a compact horizontal icon-based layout.

Display:

* Startups
* Businesses
* Agencies
* Founders

Prioritize the icons and audience names to conserve vertical space.

### Services

The four services become compact expandable rows/cards.

Each row contains:

* Icon
* Service name
* Expand/collapse indicator

When expanded, the service description and `LEARN MORE` action are revealed.

This keeps the mobile page compact without removing information.

---

# Visual Design

Follow the established portfolio design system.

* Near-black background
* Neon green accent
* White primary text
* Gray secondary text
* Thin subtle borders
* Rounded cards
* Subtle matrix/binary background
* Minimal glow effects
* Consistent spacing
* Consistent iconography

Do not introduce a new visual style specifically for this page.

---

# Interactions

### Desktop

* Service cards have subtle hover states.
* Buttons have subtle hover transitions.
* Icons can have a slight glow/scale interaction.
* Matrix background remains subtle.

### Mobile

* Services expand/collapse.
* Buttons remain full-width where appropriate.
* No large hover-dependent interactions.
* Preserve the compact layout.

---

# Important Design Decisions

* **Do not include the large hero graphic.**
* `WHAT I DO` and `WHO I WORK WITH` are positioned side-by-side on desktop.
* `HOW I CAN HELP` follows beneath them.
* The four service offerings remain visually prominent.
* `WHO I WORK WITH` should not consume excessive vertical space.
* The bottom CTA remains compact.
* Mobile prioritizes information density and usability.
* Do not add ratings, testimonials, statistics, or unrelated sections to this page.
* Do not change the established portfolio visual language.

The approved mockup should take precedence over any previous version of this page specification.
