# Ijeri Omitogun Portfolio

## Project Overview

This repository contains the source code for my personal software engineering portfolio.

The website is intended to communicate three things:

1. Technical ability
2. Design ability
3. Professional experience

The site should feel like a premium product rather than a traditional portfolio.

The approved mockups inside `/assets` are the source of truth.

Do not redesign pages.
Do not replace layouts.
Do not invent additional sections.

Implementation should faithfully recreate the approved mockups.

---

## Goals

- Fast
- Accessible
- Mobile-first
- Smooth animations
- Production-quality code
- Highly reusable Vue components

---

## Technology Stack

- Vue 3
- TypeScript
- Tailwind CSS
- GSAP
- Vue Router
- Vite

---

## Development Order

1. Global Layout
2. Navigation
3. Shared Components
4. Home
5. About
6. Experience
7. Services
8. Portfolio
9. Testimonials
10. Contact

Desktop implementation should be completed before mobile.

---

## Design Philosophy

The design is intentionally minimal.

The focus is:

- typography
- spacing
- motion
- hierarchy
- subtle interactions

Animations should feel intentional rather than flashy.

Every section should have breathing room.

Consistency is more important than novelty.
