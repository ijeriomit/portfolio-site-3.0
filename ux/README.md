# Ijeri Omitogun Portfolio

## Project Overview

This repository contains the source code for my personal software engineering portfolio.

The website is intended to communicate three things:

1. Technical ability
2. Design ability
3. Professional experience

The site should feel like a premium product rather than a traditional portfolio.

The approved mockups inside `/assets` are the source of truth.

Do not redesign pages.
Do not replace layouts.
Do not invent additional sections.

Implementation should faithfully recreate the approved mockups.

## Design Philosophy

The design is intentionally minimal.

The focus is:

- typography
- spacing
- motion
- hierarchy
- subtle interactions

Animations should feel intentional rather than flashy.

Every section should have breathing room.

Consistency is more important than novelty.

This redesign is being implemented inside an existing codebase.

The goal is not to rebuild the application from scratch.

Instead:

- Preserve existing functionality whenever possible.
- Reuse existing components whenever practical.
- Refactor rather than rewrite.
- Maintain compatibility with the existing project structure.
- Implement the approved UX mockups while minimizing unnecessary architectural changes.

If implementation details conflict with the approved mockups, prioritize matching the approved UX while preserving existing functionality.
